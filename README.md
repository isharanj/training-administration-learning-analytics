# training-administration-learning-analytics
Power BI dashboard for training administration, compliance, session analytics, and data quality monitoring.
Training Administration & Learning Analytics Dashboard

Project Overview

This project uses Microsoft Power BI to analyze employee training data and present insights through an interactive dashboard. It helps monitor training completion, attendance, session utilization, and data quality.

Objectives

- Monitor training enrollment and completion.
- Analyze attendance and no-show enrollments.
- Identify overdue mandatory training.
- Detect duplicate enrollment IDs, unknown employee records, and completed records with missing scores.
- Present key training metrics through interactive visuals.

Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Excel and CSV datasets
- GitHub

Dashboard Pages

1. Executive Scorecard: Training KPIs and completion trends.
2. Compliance Analysis: Overdue mandatory training by department and manager.
3. Session Analysis: Enrollments by course, no-shows, session capacity, and slicers.
4. Data Quality: Duplicate IDs, unknown employees, and missing scores.

Data Quality Findings

The practice dataset includes intentionally introduced data-quality issues, including duplicate enrollment IDs, employee IDs that do not match the roster, and completed records with missing scores.

How to Use

1. Download the Power BI ".pbix" file from this repository.
2. Open it using Power BI Desktop.
3. If prompted, update the data source paths to match the location of the included datasets.
4. Use the slicers to explore the report.
